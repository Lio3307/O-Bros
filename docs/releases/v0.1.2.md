## O-BROS 0.1.2

### New
- **Restart and install.** After an update is downloaded, one button closes O-BROS, installs the update and opens it again. If a terminal is still running something, or a file is not saved, it tells you first.
- **A clearer update card** in Settings > About and updates: a green dot and a Latest tag when you are up to date, New when a version is available, a progress bar while it downloads, and Ready when it can be installed.
- **The Projects header stays in view** while you scroll your folders, together with the agent buttons and the folder you are in.

### Changed
- Agent buttons show the brand icon with a status dot, so they fit any sidebar width. The name is in the tooltip. "Claude Agent" is now shown as "Claude".

### Fixed
- Many open terminals no longer add work for every line of output.
- Opening sessions quickly one after another could show the earlier session. Long sessions now load the first 200 messages with a button for more.

### Good to know
- **Updating:** Settings > About and updates > Check for updates > Download > Restart and install. Anything still running in a terminal stops, and your tabs come back as new terminals in the same folders. Claude and Codex keep their conversations, so you can resume them from History. Save your files first.
- The automatic reopen starts with this version. Updating from 0.1.0 or 0.1.1 still closes the app, and you open it yourself.
- The app is not code-signed yet, so Windows SmartScreen may warn you and macOS will ask you to confirm opening it. macOS cannot update itself: download the new `.dmg`.

### Downloads
