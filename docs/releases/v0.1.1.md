## O-BROS 0.1.1

A small fix release for 0.1.0.

### Fixed
- Agent buttons in Projects no longer lose their icon when the sidebar is narrow, and the terminal button keeps its size.
- Closing the window while a terminal was still printing could show a JavaScript error dialog. It no longer does.

### Changed
- Agents found on your computer use their short name ("Claude", "Codex", "Gemini") when O-BROS knows the command. The ACP Registry name is used only for agents it does not know.

### Good to know
- If you already added an agent in 0.1.0, its name stays as it was. Rename it in Settings > Agents, or remove it and add it again.
- Update from the app: Settings > About and updates > Check for updates. Windows and Linux (AppImage) can update in place. On macOS, download the new `.dmg` from this page.
- The app is not code-signed yet, so Windows SmartScreen may warn you and macOS will ask you to confirm opening it.

### Downloads
`O-BROS-0.1.1-win-x64.exe` (Windows), the `.dmg` and `.zip` (macOS), the `.AppImage` (Linux).
