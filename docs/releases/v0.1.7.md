## O-BROS 0.1.7

This version fixes **Check for updates**, which always said "Could not check for updates" in 0.1.5 and 0.1.6. Everything from [0.1.6](https://github.com/Lio3307/O-Bros/releases/tag/v0.1.6) is included.

### Fixed
- Check for updates now reaches GitHub again. The updater was loaded in a way that left it empty, so no check was ever made.

### Good to know
- **Updating from 0.1.5 or 0.1.6:** those versions cannot update themselves, so download and run the installer below once. From 0.1.7 on, Settings > About and updates > Check for updates works again.
- The app is not code-signed yet, so Windows SmartScreen may warn you and macOS will ask you to confirm opening it. macOS cannot update itself: download the new `.dmg`.

### Downloads
`O-BROS-0.1.7-win-x64.exe` (Windows), the `.dmg` and `.zip` (macOS), the `.AppImage` (Linux).
