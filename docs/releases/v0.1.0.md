## O-BROS 0.1.0

First public version. A terminal-first desktop workspace for the Claude and Codex command-line tools, and any other agent CLI you use.

### What you can do
- Run real terminals with tabs and splits, one set per project folder. Switching folders shows only that folder's terminals; the others keep running.
- Start Claude, Codex or any agent CLI in the selected folder. Pick up to two buttons in Settings > Agents; O-BROS finds what you have installed using the ACP Registry and your PATH, and shows if each one is connected.
- Ctrl+click a file:line in a terminal to open it in the editor at that line.
- Edit files with CodeMirror (14 languages, snippets, linting, formatting).
- Review git changes, stage, commit and switch branches.
- Browse and resume Claude and Codex history, and clean up old sessions.
- See your usage limits in the status bar, and what each terminal costs in the Resource Manager.
- Settings > Storage and memory shows every folder O-BROS uses, in plain words.

### Good to know
- Tested on Windows 11. macOS and Linux builds are included but untested.
- The app is not code-signed yet, so Windows SmartScreen may warn you and macOS will ask you to confirm opening it.
- Updates are only checked when you press the button in Settings > About and updates.
- O-BROS does not sign in for you or store your tokens. It reads the logins Claude and Codex already have on your computer.
- One network request is made when you open Settings > Agents: the public ACP Registry list of agents. Nothing about you is sent.
