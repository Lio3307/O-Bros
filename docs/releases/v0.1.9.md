## O-BROS 0.1.9

Team members you can rely on, code and a terminal side by side, and far fewer notifications that mean nothing.

### Highlights
- **Team members run one task at a time (wot skill 2.0.0).** Claude, Codex, Gemini CLI and OpenCode members now use each agent's own non-interactive mode. "Finished" means the task really ended, a message can no longer stay unsent, and the lead gets the agent's final answer instead of reading a screen. Follow-ups continue the same conversation, and a sign-in problem or usage limit comes back with the reason. Choose what a member may do when it is summoned: read only (the default) or edit files. You can watch a member and stop its task with Ctrl+C, but no longer type into it. Other agents keep the interactive way. **O-BROS offers the skill update at start: press Update all, then restart your agents.**
- **See two tabs side by side.** Drag a tab onto a side of the work area, right-click a tab or a file, or use the split buttons while a file is open. Any two tabs work, such as code and a terminal. Opening a file swaps only the editor side, and the split comes back after a restart.
- **Delete several conversations in History at once,** with a confirmation that says how many.
- **The Files panel shows git changes:** the branch, and colors for changed, new, deleted and renamed files.

### Clearer
- **Continue in another agent** opens a dialog with the conversation, a list of the agents on your computer and what will happen.
- **Every "choose one" list works the same way,** with a search box on long lists. Find a repository or branch by typing.
- **The Activity log** has search, a filter by type and pages.
- **The status bar only shows usage it can read.** Settings > Agents says why an agent is missing and how to fix it.
- **A clearer Resource Manager,** with agent icons, memory bars and local servers in their own section.
- **Clearer notification names:** "Command finished" or "Claude finished its reply", with the folder below.

### Fixed
- **Notifications no longer come when nothing happened.** A running dev server, typing without sending, pasting a long prompt and Ctrl+C never notify.
- **Agents no longer leave a `debug.log` in your project** when a sandboxed agent such as Codex runs git.
- **Code colors now cover every language,** and files the editor does not know are colored by their shape.
- **The problem list no longer flickers** on lines with many problems.
- **The port check pauses while O-BROS is minimized.**

### Removed
- **Tone in Settings > Appearance** (Midnight, Slate and the others). If you had one chosen, O-BROS goes back to your theme's own colors. Your theme and picture stay.

### Good to know
- O-BROS has only been tested on Windows 11. macOS and Linux installers are built, but those systems have not been tested.
