## O-BROS 0.1.8

A big one: themes and a new look for the whole app, a much better editor, plan usage for more agents, and a lighter, faster app. Everything from [0.1.7](https://github.com/Lio3307/O-Bros/releases/tag/v0.1.7) is included. The full list is in the [changelog](https://github.com/Lio3307/O-Bros/blob/main/CHANGELOG.md).

### Highlights
- **76 themes for the whole app**, plus import from Warp, Alacritty and Windows Terminal (Settings > Appearance > Theme).
- **Your own look:** a picture behind the app, the same on every system. Add a tone such as Midnight, Slate or Pine to color the whole app.
- **A better editor:**
  - Vim mode.
  - Smarter suggestions with nothing to install.
  - Indent guides.
  - Your choice of text cursor, with smooth movement and a short trail.
  - Colors for about 140 more languages, and image preview.
  - Open files follow changes on disk.
- **Plan usage for Grok and ClinePass** next to Claude and Codex. Usage turns red near the limit.
- **Every agent shows what it is doing** from its icon on tabs, sessions and team members.
- **Agents and gh or glab:** Ask me, Never allow or Allow, like Agents and git (Settings > Integrations).
- **Local servers** started in your terminals are listed on the monitor page.
- **Paste a screenshot into a terminal** with Ctrl+Shift+V, and drop several files and folders on a terminal at once.

### Faster and lighter
- **About 300 MB less memory with a TypeScript file open.** The TypeScript language server now runs one checker instead of two.
- **Resizing the window or a pane no longer stutters** the terminal.
- **Faster start, fewer lag spikes,** and nothing polls while O-BROS is minimized.
- Memory numbers now match Task Manager.

### Fixed
- **The git guard could be skipped from PowerShell or cmd** when a command had an odd number of quotes, which includes every multi-line `git commit -m`.
- **Agent screens looked broken in the terminal:** dashed lines and gaps in block-character logos.
- **"Finished" notifications appeared while the agent was still working.**
- **Team members were cancelled while they were still loading.**

### Good to know
- **Updating from 0.1.7:** go to Settings > About and updates > Check for updates. From 0.1.5 or 0.1.6, download and run the installer below once.
- **The app is not code-signed yet,** so Windows SmartScreen may warn you and macOS will ask you to confirm opening it. macOS cannot update itself: download the new `.dmg`.

### Downloads
`O-BROS-0.1.8-win-x64.exe` (Windows), the `.dmg` and `.zip` (macOS), the `.AppImage` (Linux).
