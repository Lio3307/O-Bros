## O-BROS 0.1.6

This version lets you continue a conversation in another agent when one hits its limit, keeps your own copy of your conversations, and shows where your disk space goes. It works with whichever agent CLIs you have installed.

### Continue in another agent
- **Continue with…** on a conversation in History, or right-click a terminal tab > **Continue in another agent…**, and pick any of your agents. It starts in the same folder with a handoff as its first message: what you asked, what the agent answered, the files changed in git, and where to read the full conversation. No model is needed, so it works after a limit.
- Conversations continued this way form a thread, shown as a chip such as "Claude → Codex" in History, and the continued one is titled "Continued: …".
- **Secrets stay out of handoffs.** Anything that looks like an API key, token, password or private key is replaced with `[hidden]` before the next agent gets it, and the notice says how many were hidden. It is a safety net, not a guarantee.

### Your conversations and your disk
- **Universal history.** O-BROS keeps a small plain-text copy of your Claude and Codex conversations in one folder you control, `o-bros-history`. Move it or choose how long to keep copies in Settings > Storage and memory.
- **Choose where conversations are saved.** Move an agent's conversations to another drive to free space. The agent, History and resume keep working. Works for Claude, Codex, Gemini CLI, Qwen Code, Cline, GitHub Copilot CLI, Goose and Cursor Agent. **Move back** returns them.
- **Your disks** shows every drive's free space and what your agents keep on it, and turns red when a drive is nearly full.
- Storage and memory now explains every button: what it does, and whether it is safe, can be undone or is permanent.

### Team of agents (wot)
- Team members now live under the terminal that summoned them in Projects. Click one to see its terminal, with Back and Stop. Stopping a member always asks first.
- `wot wait --any` waits for whichever member finishes or asks first. `wot spawn` can pass options to the agent and run it in another folder with `--cwd`.
- wot skill 1.5.0. O-BROS offers the update at start.

### Git and projects
- Pick any repository on the Git page without changing the selected project, including repositories deep inside a folder (Settings > Project folders > How deep to look, 1 to 6 levels).
- The Git page, file tree and Projects update by themselves while agents work.

### Security
- The installed app always loads its own page, ignores debugging options, and accepts requests only from its own window.
- Running from source (`npm run dev`) uses its own data folder and never touches the installed app's settings or keys.
- Built on Electron 45 with every package on its latest stable version, and `npm audit` reports no vulnerabilities.

### Fixed
- Codex team members failing with "Access is denied" when O-BROS was started from another terminal app.
- A member that exited at start or was stopped with Ctrl+C no longer looks finished, and a long `wot send --file` is always submitted.
- A member asking a question no longer shows "Working" when you open it.
- A whole drive added as a project folder now lists its repositories.
- Collapsed project folders stay collapsed.
- The History filter: the Delete button, the Team only box and the hover icons look right again.
- The full list is in the CHANGELOG.

### Good to know
- History, saved sessions, continuing a conversation, plan usage limits and account switching read only Claude and Codex conversations. You can continue them in any agent you have installed.
- **Updating from 0.1.5:** Settings > About and updates > Check for updates > Download > **Restart and install**.
- The app is not code-signed yet, so Windows SmartScreen may warn you and macOS will ask you to confirm opening it. macOS cannot update itself: download the new `.dmg`.
