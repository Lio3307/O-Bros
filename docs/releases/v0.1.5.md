## O-BROS 0.1.5

This version keeps agents out of your git history, lets agents work as a team, and brings code intelligence, merge conflicts and custom providers into the app. It works with whichever agent CLIs you have installed.

### Agents and git
- **Agents ask before git changes.** When an agent started in O-BROS commits, pushes, or creates, deletes or renames a branch, O-BROS pauses it and asks you. No answer in 100 seconds means no. Settings > Terminal > Agents and git.
- **Commits by agents are yours.** Agent commits use the name and email you set, and "Co-Authored-By" and "Generated with" lines are removed unless you allow them. Before a push, O-BROS warns you if a commit still shows an agent.
- **Activity log and agent monitor.** The new Activity page shows every running agent with its CPU and memory, and a timeline of sessions, git requests with your answers, and team members.

### Team of agents (wot)
- Ask your agent to bring in another one ("ask gemini to review this"). Install the wot skill once in Settings > Team (wot). Your agent can then summon any installed agent CLI, send it a task, wait for it and read its answer. The Team view shows each member live and turns red when one asks a question.
- Idle members can be stopped automatically to free memory, and their conversations can be found and deleted from History.

### Editor
- **Code intelligence from language servers.** Completions, hover types, errors as you type, go to definition (F12), find references (Shift+F12) and parameter hints, for TypeScript/JavaScript, Python, Rust, Go, C/C++, Java, PHP, CSS, HTML, JSON, YAML, Markdown and SQL. Settings > Language servers shows what was found and how to install the rest.
- **Color themes** for the editor and the terminal together: O-BROS, One Dark, Dracula, GitHub Dark, Monokai and Solarized Dark.

### Git
- **Merge conflicts.** A merge, rebase, cherry-pick, revert or stash that stops on conflicts shows every conflicted file. Pick Use current or Use incoming, or fix the file and mark it resolved, then Commit merge, Continue or Abort.
- **Side-by-side diff** with line numbers. When a line changes, only the words that changed are highlighted.
- **Review what the agent changed** since the selected terminal started, with a button to put each file back.
- The Git page names the folder you are in and lists the repositories inside it like a file browser.

### Providers and accounts
- **Custom providers.** Add your own Anthropic- or OpenAI-compatible endpoint with its model and API key, and start an agent button with it. The key is encrypted, shown only by its last 4 characters and never exported. Test connection checks the URL, the key and the model.
- Settings > Provider accounts lists every agent CLI you have installed and how it signs in, without reading any key.
- A usage note for every agent, and OpenRouter credit in the status bar.

### Also
- **Backup and restore settings** to a JSON file. Accounts, logins and keys are never included.
- New versions are announced in the app, with Download and Restart to update.
- A graphics card setting to save about 35 MB of memory.
- Search inside your saved conversations in History.
- A notification when an agent asks you a question.
- Many fixes. The full list is in the CHANGELOG. Highlights:
  - folders under a drive root such as `E:\` work,
  - closing never hangs,
  - git checks no longer fail at random on Windows,
  - the Problems count includes language server errors.

### Removed
- Snippets (language servers give completions instead), the prompt library and Send to terminal.

### Good to know
- History, saved sessions, plan usage limits and account switching read only Claude and Codex data. Other agents keep their own history.
- **Updating from 0.1.4:** Settings > About and updates > Check for updates > Download > **Restart and install**.
- The app is not code-signed yet, so Windows SmartScreen may warn you and macOS will ask you to confirm opening it. macOS cannot update itself: download the new `.dmg`.
