## O-BROS 0.1.4

This version makes the Git side much more complete, and adds ways to work with Claude, Codex and other agents without leaving the app.

### Git
- **History and graph.** See the commits of a repository, and open the **Graph** to see branches and merges as colored lanes. Pick one branch or All branches from a dropdown, open a commit to see its files, and read its diff.
- **Pull, Push and Stash.** Pull only fast-forwards, so it never makes a merge on its own. Push publishes a new branch for you. Stash puts your changes aside and brings them back.
- **Branch actions.** Create, rename and delete branches, change the last commit message, or undo the last commit without losing its changes.
- **Folders of repositories.** If the folder you opened contains several repositories, the Changes panel lists them and you pick one. A back button returns to the list.
- **Colored diffs.** Added lines are green and removed lines are red.

### Working with agents
- **Prompt library.** Keep the prompts you use often and send one to the focused terminal with `Ctrl+Shift+L`.
- **Send to terminal.** Select code or open a diff and send it into the terminal, with its file path and an optional question.
- **Command palette.** `Ctrl+Shift+P` searches every action in the app.

### Also
- Settings pages are grouped under labels.
- Pane buttons show only on the pane you are in.

### Good to know
- O-BROS never force pushes. If a change would need one, you are told first.
- Git never asks for a password inside the app. If a remote needs one, sign in once from a terminal.
- Send to terminal works best with an agent such as Claude or Codex. A plain shell runs each line of a block as soon as it is inserted.
- **Updating:** Settings > About and updates > Check for updates > Download > **Restart and install**. O-BROS reopens by itself. Anything still running in a terminal stops, and your tabs come back as new terminals in the same folders.
- The app is not code-signed yet, so Windows SmartScreen may warn you and macOS will ask you to confirm opening it. macOS cannot update itself: download the new `.dmg`.
