Add language servers, block agent git changes and lower memory use

Editor
- Code intelligence from the language servers installed in the project
  or on the computer: completions, hover, errors as you type, go to
  definition (F12), find references (Shift+F12), parameter hints
- Settings -> Language servers: what was found, install hints, turn one
  off or give your own command, running servers with Stop
- Server and oxlint errors are shown together; hover HTML is sanitized
- Snippets removed

Agents
- Agents may not commit, push or create branches or worktrees by
  default (Never allow / Ask me / Allow in Settings -> Terminal);
  wot skill 1.3.0 tells agents to hand the commit to the user
- Provider accounts lists every installed agent that needs a sign-in
  or an API key, with its status and how to sign in; API key
  variables are checked by name only

Memory
- Memory leak test; no leak found
- Settings, Changes, History and the monitor load when first opened;
  the startup bundle is 24% smaller
- Memory figures show private memory, like Task Manager
- Graphics card setting saves about 35 MB

Fixes
- Reading the Windows process list failed when any program had a
  control character in its command line, which broke git checks at
  random
- Slow git checks are logged, and the git guard tests print the
  agent's output when they fail
